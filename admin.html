ئکەمجار: بەستنەوە بە GitHub

تۆکن چاوا دهێتە دروست کرن ؟
  1. بچۆ GitHub ← وێنەی پرۆفایل ← Settings ← Developer settings
  2. Personal access tokens ← Fine-grained tokens ← Generate new token
  3. Expiration: 1 year. لە Repository access تەنها ڕیپۆی ئەم سایتە هەڵبژێرە
  4. لە Permissions ← Repository permissions ← Contents بکە بە Read and write
  5. Generate token، دواتر کۆپیی بکە و لێرە دایبنێ. تەنها یەکجار پیشان دەدرێت.
